# 登山回憶 PWA 版方案

目標：不付任何費用，做出可以給別人用的網頁版 App。使用者回家後匯入 GPX 軌跡和照片，得到一篇視覺化日誌，並能在貼著真實空拍影像的立體地形上播放整趟路線。

## 已決定的事

| 項目 | 決定 |
|---|---|
| 形式 | PWA，取代需要 Apple 開發者費用的原生版 |
| 託管 | GitHub Pages |
| 授權 | repo 開源，程式碼採 MIT |
| 軌跡來源 | 使用者從自己的登山 App 匯出 GPX |
| 平面地圖 | Thunderforest Outdoors，使用者輸入自己的金鑰 |
| 立體播放的地表 | 國土測繪中心正射影像（線上） |
| 地形高程 | 公開的免費高程圖磚服務（線上） |
| 自己託管的資料 | 只有程式和約 2MB 的景點資料 |
| 魯地圖 | 不再使用（檔案 2.9GB，GitHub Pages 放不下） |

沒有伺服器、沒有資料庫、沒有帳號系統，repo 裡也沒有任何金鑰。

## 技術選擇

| 項目 | 選擇 |
|---|---|
| 前端 | Vite + TypeScript |
| 地圖與立體地形 | MapLibre GL JS（內建立體地形） |
| 使用者資料 | 瀏覽器本機資料庫（IndexedDB） |
| 網址 | `<帳號>.github.io/<repo>` |

## 使用流程

1. 爬山時，使用者用自己的登山 App 錄軌跡、用相機拍照。我們的 App 不用開。
2. 回家後打開網址。新裝置第一次使用時，先走完金鑰設定教學。
3. 建立一趟行程，匯入那趟的 GPX 檔，路線出現在地圖上。
4. 選取當天的照片，App 依拍攝時間把每張照片放到軌跡上。
5. 得到日誌：地圖、照片、沿途景點、海拔剖面、日記、立體播放。

## 第一次使用的金鑰教學

新裝置第一次開啟時顯示，一步一個畫面：

1. 說明為什麼需要金鑰：地圖由 Thunderforest 提供，每個人用自己的免費額度。
2. 開啟 Thunderforest 註冊頁的按鈕，附上要填哪些欄位的說明。
3. 說明註冊後在哪裡找到金鑰，附示意圖。
4. 貼上金鑰的輸入框。貼上後立刻載入一張測試圖磚，確認金鑰有效才能繼續。
5. 完成，進入 App。

規則：

- 金鑰只存在使用者那台裝置的瀏覽器，不會傳給任何人。教學裡要明講這一點。
- 金鑰無效或額度用完時，顯示原因並引導回設定頁，地圖不能只是空白。
- 設定頁可以隨時更換或清除金鑰。
- 匯出的行程備份檔不包含金鑰。
- 立體播放的空拍影像與地形不需要金鑰。

## 立體播放怎麼做到像參考影片

1. **地形**：MapLibre 內建立體地形，讀取線上的高程圖磚，不用自己建模型。
2. **地表**：底圖用正射影像，山的表面是真實的森林、裸岩、溪谷。
3. **鏡頭與路線**：路線畫成貼地的線，鏡頭沿 GPX 軌跡移動，走到拍照點時照片彈出。

和 Google 地球的差別：樹木和建築是貼在山坡上的平面影像，不是立體的。地形解析度約 30 公尺，整體山形真實，近看小尺度的岩壁會被抹平。

## 資料從哪裡來

| 資料 | 來源 | 必要性 |
|---|---|---|
| 路線（經緯度、時間、海拔） | 使用者匯入的 GPX | 強烈建議 |
| 照片與拍攝時間 | 使用者選取的照片 | 必要 |
| 照片的座標、海拔、拍攝方向 | 照片的中繼資料 | 有就用 |
| 沿途景點 | 已做好的景點資料（23,718 筆） | 自動 |
| 當天天氣、日出日落 | Open-Meteo 歷史天氣（非商業免費） | 選配 |
| 日記、照片註解 | 使用者輸入 | 選填 |

照片對到路線的規則：

- 有 GPX：依照片的拍攝時間，找軌跡上同一時刻的位置。照片沒有定位也能放上去。
- 沒有 GPX：用照片自己的座標連成路線，並明白告訴使用者「路線由照片位置連成，匯入 GPX 會更準」。

## 畫面風格

使用者會把它加到主畫面全螢幕使用，所以要像一個 App，而且看起來輕鬆、有手作日誌的感覺。

| 項目 | 做法 |
|---|---|
| 底色 | 淡淡的苔綠米色 `#EEF1E2`，卡片用暖白 `#FBFBF4` |
| 文字 | 深森林綠 `#24352C`，次要文字 `#4E5F53` |
| 強調色 | 日出橘 `#B84A22`，只用在主要按鈕、路線、目前位置 |
| 標題與日記字體 | 霞鶩文楷 TC（手寫楷體感） |
| 內文字體 | Noto Sans TC |
| 形狀 | 大圓角卡片（20 到 28）、膠囊按鈕、柔和陰影 |
| 照片 | 拍立得樣式：白邊、微微傾斜、下方手寫註解 |
| 裝飾 | 首頁與教學頁有山稜與太陽的插畫；日記卡像貼了紙膠帶的便條 |
| 全螢幕 | 不畫瀏覽器式的工具列，上下留出瀏海與底部橫條的安全距離，主要操作放在拇指碰得到的下半部 |

## 使用者資料與隱私

- 照片和行程存在使用者瀏覽器的本機資料庫，不上傳。
- 照片匯入時縮小到長邊 2048 像素再存。
- 提供「匯出這趟行程」和「匯入」，同時是備份方式，也是把行程分享給別人的方式。
- 啟動時向瀏覽器要求持久儲存，並引導使用者「加入主畫面」。

## 授權

- `LICENSE` 為 MIT，README 註明僅適用於程式碼。
- 景點資料來自 OpenStreetMap，採 ODbL，在 repo 內另外標示。
- App 內標示各地圖服務的來源：Thunderforest、OpenStreetMap contributors、內政部國土測繪中心、高程圖磚的提供者。

## 相較原生版會拿掉的

- 氣壓、步數、電量記錄。
- 離線使用。地圖和影像都需要網路。
- 魯地圖。

## 驗證結果（2026-11-11）

測試頁在 iPhone 17 模擬器的 Safari 上執行，畫面存在 `docs/verify/`。

| 項目 | 結果 |
|---|---|
| 空拍影像貼上立體地形 | 可行。MapLibre 加國土測繪中心正射影像加公開高程圖磚，在 Safari 正常顯示，路線貼在地形上 |
| 各圖磚服務能否從網頁讀取 | 可以。正射影像、Thunderforest、高程圖磚都允許跨網域讀取 |
| Thunderforest Outdoors 畫面 | 合歡北峰一帶有等高線、步道、中文山名與標高 |
| Thunderforest 免費方案 | 每月 15 萬張圖磚。必須標示 Thunderforest 與 OpenStreetMap。允許瀏覽器與裝置快取，禁止代理轉發與大量預先下載 |
| Safari 選照片 | 保留拍攝時間、時區與 GPS，選擇器顯示「Location Is Included」 |
| GitHub Pages 限制 | 網站 1GB、每月流量 100GB（軟性）、不可作商業用途。我們只放幾 MB，足夠 |
| 國土測繪中心通用電子地圖 | 沒有等高線、步道很少，不適合當登山平面地圖 |

## 仍未確認的事

1. **Thunderforest 條款沒有提到「使用者自備金鑰」。** 條款要求使用前先註冊，每個使用者各自註冊符合這一點，但沒有明文允許或禁止這種 App 設計。註冊是否需要信用卡，頁面上也沒寫。
2. **國土測繪中心正射影像的條款。** 官網說通用電子地圖等 WMTS 服務「提供對象不限，無需申請」，但我沒找到正射影像圖層是否在這份清單內，也沒找到用量限制。備案是 Esri World Imagery。
3. **高程圖磚的標示方式。** AWS 上的開放地形圖磚不需帳號即可讀取，授權與標示文字要照它的說明文件。
4. **真的 iPhone 上的照片。** 模擬器測的是 JPEG。真機拍的 HEIC 照片還沒測，要等部署後用實機確認。

## 建議的進行順序

1. 最小驗證（已完成，見「驗證結果」）。
2. 核心邏輯：GPX 解析、照片對位、距離與爬升、景點查詢，連同測試。
3. 金鑰教學與設定頁。
4. 行程建立流程：匯入 GPX、選照片、存進本機資料庫。
5. 日誌畫面：平面地圖、照片與景點、剖面圖、日記。
6. 立體播放：地形、空拍影像、路線、鏡頭、照片彈出。
7. PWA 化：加入主畫面、圖示、匯出與匯入。
8. 部署到 GitHub Pages，在真的 iPhone 上走完整個流程。
